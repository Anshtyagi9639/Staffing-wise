# Keyword research and page mapping

Research date: 30 October 2026. Markets: Ireland and the United Kingdom, English.

## Method and limitations

**No SEO platform or paid keyword tool was connected** (no Google Ads Keyword Planner, Semrush, Ahrefs or Search Console data).
Therefore **this document contains no search volumes or difficulty scores**; none have been estimated or invented. The evidence
used was:

1. **Client brief**: the seed terms in the content document (section 10) and the client's list.
2. **Google Autocomplete** (`suggestqueries.google.com`, `gl=uk` and `gl=ie`, 23 seed phrases). Autocomplete shows that a
   phrase is searched often enough to be suggested. It does not measure volume. No suggestion usually means low volume.
3. **Search results review**: who ranks for the core customs-staffing queries and how they position themselves.
4. **Existing site**: staffingwise.ie (Wix) has no service pages, so there is no ranking history to protect apart from the blog.

Raw autocomplete observations (both markets returned the same results):

| Seed | Autocomplete evidence |
|---|---|
| outsourced customs clearance | none |
| customs clearance outsourcing | → "customs broker outsourcing" |
| customs clearance staff | → "customs clearance staff", "customs clearance team", "customs declaration staff", "customs broker staff" |
| customs declaration processing | → "customs declaration processing" (mixed with parcel-tracking "processing complete" queries) |
| outsourced customs / dedicated customs / offshore customs clearance | none relevant ("offshore" returns consumer parcel queries) |
| outsourcing for freight forwarders / freight forwarding back office outsourcing | none |
| outsourced accounting staff | → "outsourced accounting staff", "outsourced accounting team", "outsourced accounting department" |
| outsourced bookkeeping uk | → "outsourced bookkeeping services uk", "outsourced accounting uk"; Ireland: "accounting outsourcing ireland" |
| outsourced admin support | → "outsourced administrative support", "outsource admin support services" |
| offshore staffing | → "offshore staffing solutions", "offshore staffing company", "offshore staffing services", "offshore staffing agency" |
| dedicated offshore staff / offshore staffing ireland | none |

**Search results review (customs queries):** results are dominated by customs brokerages and chambers of commerce selling
*declaration services* (for example "we make declarations on your behalf"), plus GOV.UK guidance on appointing an agent. No result
positions itself as *dedicated staff for brokers and forwarders*. This is Staffing Wise's angle: it supplies capacity to the
businesses that already do customs work, rather than competing with them as a broker.

### Conclusions

- Core customs-staffing phrases have **low but highly qualified** demand. One strong, specific page beats several thin variants.
- "Offshore" is ambiguous in customs searches (parcel tracking) and is not the language buyers use in the brief. Use "dedicated
  overseas staff" in copy, with "offshore staffing" as a secondary term on the homepage and How It Works only.
- **"Outsourced customs agents"** is risky: Staffing Wise supplies *staff*, not a customs agent/representative service. Do not
  target it as a primary keyword until question 20 in client-questions.md is answered.
- Finance and admin terms have more demand but much more competition (accountancy firms, VA agencies). Pages target the
  "staff"/"support" variants that match the dedicated-staff model.

### Supporting questions answered on the site (AEO)

What is customs clearance staffing? · How does the dedicated staffing model work? · Who employs the staff? · Will staff work
exclusively for my business? · Which customs systems can staff use (Thyme IT, CDS, AIS/AES)? · Can staff support CHEDs and
IPAFFS? · How quickly can someone start? · How is this different from a recruitment agency? · What information do I need to
get started? (Contact page: role, workload, systems, hours.)

### Pages deliberately not created

"Customs Clearance Outsourcing", "Dedicated Customs Agents", "Offshore Customs Clearance Services" and "Dedicated Offshore
Staffing Solutions" were proposed in the project brief. Each would target the same intent as `/customs-clearance-staffing` or the
homepage with no distinct content, which would mean thin, cannibalising doorway pages. Their terms are covered as secondary keywords. Revisit after 3
months of Search Console query data: create a separate page only if a query shows distinct intent and enough impressions.
